🚀 Mach-Zilla

Mach-Zilla is a smart productivity and performance-tracking web application designed to help students and developers measure, analyze, and improve their work speed and focus.

Inspired by the concept of Mach speed (ratio of actual speed to ideal speed), Mach-Zilla introduces a unique Mach Score that quantifies productivity in a simple and meaningful way. The project focuses on tracking tasks, time efficiency, and focus levels to provide actionable insights through visual dashboards.

✨ Key Features

📋 Task Speed Tracking – Log tasks and measure planned vs actual completion time

⏱️ Focus Sessions – Pomodoro-based focus tracking with session analysis

📊 Performance Dashboard – Visual charts for daily and weekly productivity

⚡ Mach Score System – A single metric that represents productivity speed and efficiency

💾 Local Data Storage – No backend required, fast and lightweight
